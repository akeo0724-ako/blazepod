BLAZEPOD カートトレーニング

8歳・ジュニア / ポッド4個

今日のメニュー

毎日やるコツ
7分で切り上げる。残り時間があっても「もう1回やりたい」で終わらせるのが、翌日また乗ってくる秘訣です。 反応の練習は疲れると質が落ちて逆効果になるので、長さより毎日の回数で積み上げます。

進め方の型（どのテーマでも同じ）

  1. 1分／ウォームアップ「めざまし4タッチ」で目と手を起こす
  2. 3分／その日のメインドリル（下のカード）
  3. 2分／サブドリル（別テーマを軽く）
  4. 1分／締めのゲーム（記録更新 or 親子バトル）

ドリル一覧

カードを開くと、置き方の図・やり方・アプリで設定したい値・声かけが出ます。

BLAZEPODアプリ 操作マニュアル

英語UIの読み方つき。公式ユーザーマニュアル（2026年11月版）に沿っています。

いちばん大事なこと
無料プラン（BlazePod Go）でも、RANDOM（ランダム）の光り方なら自分でドリルを作れます。 このメニューの11種はすべてランダムなので、最初に11個作ってコレクションにまとめてしまえば、 あとは毎日それを開いて上から順にやるだけになります。

1. 画面の地図

画面のいちばん下に5つのアイコンが並んでいます。これが基本の5画面です。

アイコン英語名何の画面か
🏠Home Screenホーム。お気に入り・最近やった分・作成ボタン
⏱Performance Tests体力テスト（Pro機能）
🔵Training Hub世界中のドリルを探す画面（中央のロゴ）
📊Analytics記録・履歴・グラフ
⚙️App Settingsプレイヤー管理・音のオンオフなど

画面の右上には常に Pod Settings アイコンがあり、数字＝今つながっているポッドの数です。 ここが「4」になっていれば準備OK。

ホーム画面には上から Challenges / Training Hub / Following / My Activities（＋ボタンで自作）/ Favorites / My Collections / Recent が並びます。

2. 最初の1回：充電と接続

Pod settings 画面のボタンの意味
見出しの横の3つ
電球＝その一覧のポッドを全部光らせる／Ⓐ＝自動接続をまとめて入切／Bluetooth＝まとめて接続（Available側）・まとめて切断（Connected側）
各ポッドの行
左にポッド名＋バッテリー%、右に電球（この1個だけ光らせる）・Ⓐ（この1個だけ自動接続）・Bluetooth（この1個だけ切断）
Sort
並べ替え。Name（名前）/ Proximity（スマホに近い順）/ Auto connect / Last connected

※ Available Pods には「どの機器にもつながっていないポッド」しか出ません。
※ 同時接続できる数はスマホ次第（公式注記）。iPhoneは機種により最大14個とされています。4個なら余裕です。

3. ⭐ 自分のドリルを11個作る（無料でできる）

ホーム画面の My Activities にある ＋ をタップ → Create Screen が開きます。

  1. Choose Light Logic の画面になる。横にスワイプして RANDOM を選ぶ
    （RANDOM＝「叩いて消したら、次にどれが光るかはランダム」。無料で使えるのはこれ）
    → Choose を押す
  2. Defining General Setup が出る。Stations＝1、Pods（Per station）＝下の表の数 → Next
  3. 続けて Activity Duration / Lights Out / Light Delay Time / Cycles を表のとおりに設定
  4. 名前を付けて保存。日本語名でOK（例「めざまし4タッチ」）
  5. 保存したドリルを開き、⋯ → Add to a collection で 「マイメニュー」 というコレクションにまとめる

11個作るのは最初だけ。30分くらいかかりますが、これをやると毎日の操作が「コレクションを開いて上から順にタップ」だけになります。

5. 毎日の流れ（4ステップ）

① アプリを開く → 右上の数字が 4 か確認
② ホーム画面の My Collections から「マイメニュー」を開く
③ 今日のドリルをタップ → Start Now
④ 終わったら結果の Avg. Reaction と Hits を見て、「記録」タブに入れる

離れた位置から始めたいときは Start on Hit（ポッドを1回叩くと開始）。「センターもどりダッシュ」のように中心に戻ってから始めたい場合に便利です。

6. 設定項目の全対訳

General Setup — 全体の設定
Stations
Working stations
ポッドのグループ数。2人が同時に別々のポッドでやるとき2。普段は1。
Pods
Per station
1グループで使うポッドの数。ここで 1 / 2 / 4 を指定。
Distract Pods
out of total pods
気を散らすために光らせるポッドの数（Focus logic のとき）。
Cycles
繰り返す回数。2以上にすると Time between cycles（間の休憩秒数）も出る。
Activity Settings — 中身の設定
Player
誰がやるか。名前をタップすると一覧と「新規作成」が出る。結果はプレイヤーごとに Analytics に分かれて残る。
Activity Duration
終わり方。3つから選ぶ：
・Hit … 決めた回数タッチしたら終了（「20タッチ」はこれ）
・Timeout … 決めた時間で終了（「45秒」はこれ）
・Hit/Timeout … 先に来たほう
Lights Out
光の消し方。3つから選ぶ：
・Hit … 叩くまで消えない（基本はこれ）
・Timeout … 決めた時間で勝手に消える
・Hit/Timeout … 早いほう。これにすると Miss-Hits が記録される
Light Delay Time
消えてから次が光るまでの間：
・None … すぐ次（基本）
・Fixed … 決めた秒数あけて
・Random … 最小〜最大の間でバラバラに
「スタートシグナル」はここを Random にするのが肝
Competition Mode
対戦のとき：
・Regular mode … 各自が自分の光を消す
・First to hit mode … 先に叩いた人が全員の光を消す
Light Logic — 光り方のルール（5種）
RANDOM
無料で使えるのはこれ。叩いて消すと、次に光るポッドがランダムに選ばれる。このメニューは全部これでOK。
Home Base
「ホーム」のポッドを決める方式。Home base Pod color でその色を指定。
Focus
気を散らすポッドを混ぜる方式。Number of distracting Pods（数）、Distracting Pod colors（色）、Strike Out（何回お手つきで終了か）。
「③はさわるな」のアプリ版。ただしPro機能の可能性が高いので、番号ルールで代用しています。
Sequence
決めた順番に光る。Number of steps で何個光らせるか。
5つ目
マニュアルの図では選択肢が5つありますが、5つ目の名前は読み取れませんでした。実機で確認を。

8. 記録を見る（Analytics）

  • 上のカレンダーで期間、右上の人マークでプレイヤーを選ぶ
  • Analytics（グラフ）と History（一覧）をタブで切り替え
  • My Activities では Daily / Weekly / Monthly を切り替えて、ドリルごとに Avg. reaction / Avg. hits / Avg. miss hits / Avg. total hits と推移グラフが見られる
  • History画面の書き出しアイコンで結果をエクスポートできる
  • 要らない記録は左スワイプで削除

9. 既成ドリルを探すとき（Training Hub）

中央のロゴ（Training Hub）で世界中のドリルが見られます。検索窓の横のフィルターアイコンで絞り込み：

Pods
使うポッドの数で絞る ← 「4」にすると4個で成立するものだけ出る

気に入ったら ★ でお気に入り、⋯ → Add to a collection で「マイメニュー」に追加できます。

10. 困ったとき

ポッドが見つからない
① 充電は足りているか ② Bluetooth確認 ③ 他の端末につながっていないか ④ Auto connect を一度オフにして手動で接続 ⑤ Bluetoothとアプリを再起動
一覧に出るのにつながらない
少し待つ → Bluetooth再起動 → アプリ再起動 → Auto connect をオフにして手動接続
"not enough connected Pods"
ポッド数が足りない表示。Pod settings を開いて未接続を接続し Done。足りなければ充電不足（数時間充電）
途中で止まる
切断が原因。電池切れか40m以上離れたか。近づけて再接続
叩いても反応しない
① しっかり強く叩く（かなり頑丈です）② 設定が Hit で Timeout になっていないか ③ アプリ完全終了 → Bluetooth切→端末再起動→Bluetooth入
充電ベースで赤青緑に変わる
故障ではなくスリープから起きている最中のサイン。10分充電してから一度外して戻す
充電されない
充電ピンの傷、ケーブル交換、壁の充電器を使う、正しく重ねる、1個ずつ充電
完全に電源を切りたい
Pod settings でそのポッドを最大10秒長押し → Pod information → shut down Pod。充電ベースに戻すと復帰

※ 防水は IP65（防滴）。雨や濡れた芝生は平気ですが、水に沈めないこと。

13. 安全のため

  • 床置きは滑らない場所で。フローリングに靴下は転ぶ（裸足か室内シューズ）
  • 手の届く範囲にテーブルの角・ガラス・家具がないか毎回見る
  • ポッドを踏まない約束。手でタッチするドリルが基本
  • レース当日は汗をかくほどやらない。目を覚ます程度で止める
  • 夜に静かにやりたいときは App Settings → App Sounds をオフ
